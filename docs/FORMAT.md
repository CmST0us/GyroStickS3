# 日志格式（固件 ↔ 主机工具）

日志分区 `gyrolog` 是一个追加式的 4 KiB 页数组。每页只擦除一次、编程一次，所以掉电最多损坏正在写的那一页，
损坏由 CRC 检出；已写好的页永远不会被改动。页自包含，丢一页不影响其余页的解码。

## 页头（64 字节，小端）

| 偏移 | 大小 | 字段 | 说明 |
|---|---|---|---|
| 0 | 4 | magic | `GYPL`（0x4C505947） |
| 4 | 1 | version | 1 |
| 5 | 1 | flags | 0x01 会话首页，0x02 正常停止后的最后一页，0x04 此页之前有数据丢失，0x08 录制时用了 light sleep |
| 6 | 2 | payload_len | 页内有效负载字节数 |
| 8 | 4 | session_id | 录制编号，单调递增 |
| 12 | 4 | page_seq | 会话内页号 |
| 16 | 4 | first_idx | 本页第一个样本在会话中的序号 |
| 20 | 2 | n_samples | 本页样本数 |
| 22 | 2 | odr_hz | 名义输出数据率 |
| 24 | 2 | gyro_fs_dps | 陀螺仪量程 ±dps |
| 26 | 1 | acc_fs_g | 加速度计量程 ±g |
| 27 | 1 | channels | 3 = 仅陀螺仪，6 = 陀螺仪 + 加速度计 |
| 28 | 4 | session_unix | 录制开始时的 Unix 时间，0 = 设备时钟未设置 |
| 32 | 4 | sync_idx | 下面两个同步值对应的样本序号 |
| 36 | 4 | sync_st24 | 该时刻 BMI270 传感器时间（24 位，39.0625 µs/计数） |
| 40 | 4 | sync_us32 | 该时刻 MCU `esp_timer`（µs，低 32 位） |
| 44 | 2 | batt_mv | 写页时的电池电压 |
| 46 | 8 | orient | Gyroflow orientation 字符串，NUL 填充 |
| 54 | 6 | reserved | 0 |
| 60 | 4 | crc32 | CRC-32（zlib 同款）：覆盖 [0,60) 和负载 |

## 负载编码

每个通道维护：前两个样本 `prev, prev2`；两个预测器近期误差的 EMA `err1, err2`（α = 1/16）；
残差的 EMA `mean16`（α = 1/16，放大 16 倍存储）。

- 页内第一个样本原样存放（每通道 int16 小端），所以每页可独立解码。
- 其后每个样本、每个通道：
  1. 预测值：`err2 < err1` 时用二阶预测 `clamp16(2*prev - prev2)`，否则用一阶 `prev`；
  2. 残差 `d = x - pred`，Zig-zag 编码 `u = (d << 1) ^ (d >> 31)`；
  3. Rice 参数 `k = floor(log2(mean16/16 + 1))`；商 `q = u >> k` 用一元码（q 个 1 + 一个 0），再写 `u` 的低 k 位；
     `q ≥ 20` 时转义：20 个 1，然后 17 位原始 `u`；
  4. 更新 `mean16 += u - (mean16 >> 4)`，`err1 += |x - prev| - (err1 >> 4)`，`err2 += |x - (2*prev - prev2)| - (err2 >> 4)`。
- 位流高位在前，末字节补 0。

参考实现：编码器 `components/gyl/gyl_codec.c`，解码器 `components/gyl/gyl_decode.c`（主机测试用）和
`tools/gyrostick.py` 的 `decode_payload()`；`test/test_tool.py` 校验 C 和 Python 的编码结果逐字节一致。

## 时间轴

BMI270 的 FIFO 在每次读出的数据末尾附带一个传感器时间帧（`sync_st24`）。固件在每次读取后记录
`(最后一个样本的序号, 传感器时间, MCU 时间)` 作为同步点，每页保存最近的一个。如果传感器时间的前进量和读到的帧数
相差超过 4 个采样周期（FIFO 溢出等），固件会封存当前页并把下一页标记为 `GAP`。

主机工具 `build_timeline()`：按 `GAP` 页把录制切成连续段；段内样本时间 = `偏移 + 序号 × 每样本计数`
（每样本计数 = 25600 / ODR，是整数），偏移取该段各页同步点的中位数，因此对单个同步点的抖动不敏感；
24 位计数器回绕通过对照样本序号展开。段与段之间的空洞（丢失的数据）按传感器时间原样保留。

## 主机协议（USB Serial/JTAG，行文本 + 二进制页）

| 请求 | 应答 |
|---|---|
| `HELLO` | `GYLOG 1 fw=.. pages=N used=W batt=mV rec=0\|1 unix=T odr=.. ch=.. orient=..`；之后固件关闭日志输出以免污染二进制流 |
| `READ a n` | `OK a n` 后紧跟 n × 4096 字节原始页（n ≤ 256；录制中拒绝） |
| `ERASE` | 擦除所有已用页，完成后 `OK`（录制中拒绝） |
| `TIME t` | 设置系统时钟（Unix 秒），`OK` |
